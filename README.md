# 深鲸记忆体检 · dsh-memory-doctor

> 跨会话记忆的**体检 / 瘦身 / 记忆包**。本地明文、零依赖、不上传任何数据。

## 它解决什么

现在大多数记忆插件都在解决「**记住**」。但用久了真正的问题变成：

- 记忆越写越满（运行时记忆有硬上限），到点就被动归档
- 同一条记了两遍、内容差不多但措辞不同
- 「临时/进度」类内容混进长期记忆，占着预算
- 换电脑、团队协作时，记忆带不走

本插件补的就是这三件事，**不改你现有的记忆文件格式**（`~/.mnemon/runtime/` 下的 MEMORY.md / USER.md），
所以它可以和现有记忆插件共存。

## 它自己就是热记忆（不是配件）

每轮对话都会把 `MEMORY.md`（项目/环境记忆）和 `USER.md`（用户画像）**注入 system prompt**，
并附带「记忆维护协议」——所以 Agent 真的会记住，而且知道什么时候该写、写去哪、别重复写。

- 注入预算默认 6000 字符，超了截断并提示归档（不会把上下文吃光）
- 记忆是**明文 Markdown**（`~/.mnemon/runtime/`），你自己随时能看、能改、能带走
- Agent 用自带的写文件工具维护记忆，不需要额外工具调用

> ⚠️ 与 `dsh-mnemon` 等记忆插件**二选一**：都用会重复注入。只想用本插件的体检/记忆包时，
> 可以保留 mnemon 但把本插件注入关掉（后续版本会加开关）。

## 功能

| 功能 | 说明 |
|---|---|
| **体检** | 用量百分比、条目数、重复/近重复、低信息量、临时进度类，一次说清 |
| **瘦身** | 按勾选归档到 `archived/`（**先备份、只移动、不删除**，可回滚） |
| **记忆包** | 一键导出 `~/.mnemon/记忆包-日期-xxxx/`（含 manifest.json、文档、git 版本），可换机/团队共享/留档 |

## 安装

```bash
dsh plugin add dsh-memory-doctor
```
（面板安装需要本机有 pnpm；也可以直接把文件夹放进 `dsh-home/plugins/` 后重启）

## 使用

- 面板：侧栏「记忆体检」图标 → 看用量、勾选、归档、导出
- 命令：`/记忆` → 一句话看健康度

## 安全

- 只读写 `~/.mnemon/`；**不做删除**（归档 + 备份）
- 不联网、不上传；无遥测

## 未知边界

- 目前瘦身只处理 `MEMORY.md`（`USER.md` 是人格画像，建议人工编辑）
- 记忆包导入为**追加合并**，不与现有条目冲突时才加
